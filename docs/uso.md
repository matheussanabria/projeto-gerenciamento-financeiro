## 4. Documentando o Uso (`uso.md`)
  ### Como Usar o Sistema

  ### Página de Transações
  - **Adicionar Transação**:
    1. Clique no botão "Nova Transação".
    2. Preencha os campos: Descrição, Valor, Remitente, Forma de Pagamento, Pacelamento, Conta, Categoria, Subcategoria, Classe, Subclasse e Data.
    3. Clique em "Salvar".

  - **Editar Transação**:
    1. Na lista de transações, clique no ícone de edição.
    2. Faça as alterações necessárias.
    3. Clique em "Salvar".

  - **Excluir Transação**:
    1. Na lista de transações, clique no ícone de lixeira.
    2. Confirme a exclusão.
